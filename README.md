# NFT-Marketplace

React-based digital collectibles frontend with React Router, Firebase, Keen Slider, AOS, and React Icons. This is a UI project, not a verified on-chain trading platform.

## Run locally

Install Node.js and npm, then:

```bash
npm install
npm start
```

The development server typically opens at http://localhost:3000.

## Available commands

- `npm start`: run the development server
- `npm run build`: build for production
- `npm test`: start the configured test runner

## Scope

This is a frontend portfolio project. External service integrations may need configuration. No live production functionality is guaranteed by this README.
